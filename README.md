# Student Career & Placement Tracker

A full-stack web application that helps students manage
their internship and placement preparation in one place.

## Project Goal

The application allows students to track:

- Job and internship applications
- DSA preparation
- Daily preparation tasks
- Interviews
- Resume information
- Placement statistics

## Tech Stack

- Java
- Spring Boot
- MySQL
- HTML
- CSS
- JavaScript
- Git
