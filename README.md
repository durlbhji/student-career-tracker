# Student Career & Placement Tracker

A full-stack web application that helps students manage their internship and placement preparation in one place.

## Project Overview

The Student Career & Placement Tracker provides a single dashboard to organize job applications, DSA preparation, daily tasks, interviews, and resume information.

## Features

* **Dashboard:** View application statistics, DSA progress, tasks, and interviews.
* **Job Applications:** Add, edit, delete, and track job and internship applications.
* **DSA Tracker:** Manage DSA topics and monitor preparation progress.
* **Task Management:** Create, update, and delete daily preparation tasks.
* **Interview Tracker:** Record interview details, rounds, and results.
* **Resume Management:** Save and update resume information.
* **PDF Download:** Download resume information as a PDF.
* **User Registration and Login:** Register and log in to the application.
